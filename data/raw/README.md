# Raw data

`hotel_bookings.csv` is the Hotel Booking Demand dataset:

> Antonio, N., de Almeida, A., & Nunes, L. (2019). Hotel booking demand datasets.
> *Data in Brief*, 22, 41–49. https://doi.org/10.1016/j.dib.2018.11.126

Published open access under CC BY 4.0. This copy is the combined single-file
version (City Hotel H2 + Resort Hotel H1), 119,390 rows, 32 columns.

The file is frozen. Surrogate booking IDs are derived from its fingerprint and
row order, so do not re-sort or edit it.

SHA-256: `7c2ae42a7353905ea136e5c2287f17c92c5435826598bfbb8491c6f0c7b1fc06`
